# 生产环境升级说明（2026-11-14）

适用：catpaw.art 线上环境，从上一版升级到本包。

---

## 一、本次上线内容

### 前台
- **全面去商业化**：站点内不再出现 `¥` 与「元」，所有价格/费用口径统一为「积分」；「报名」改为「登记」。
- **电子票根**（新页面 `/tickets/:id`）：登记成功后凭票根到场，含场次、时段、场地、模特。
- **代拍**：支持代拍的场次，详情页在时段列表下方单独展示「代拍服务」，无需本人到场，价格与正常登记一致。
- **个人中心拆分**：原一页拆为「个人中心 / 积分明细 `/points` / 设置 `/settings`」。
- **底部 tab 加图标**并加高（52px → 64px）。
- **SVIP 专属**：场次详情可查看「同场的人」（只显示昵称，不含微信号）。
- **账号注销**：个人中心 → 设置 → 注销账号（软删除 + 匿名化）。

### 后台
- 价格口径改为「标准 / VIP / SVIP 积分」；优惠券改为「减免积分」。
- **手动录入增强**：支持名额数（1–10）、选择优惠券、可选扣积分、四种结算方式（扣积分 / 线下已收 / 线下待收 / 免费）。
- **时段回避名单**（新功能）：运营 / 管理员 / 超管可用。用于「某时段不接受某人报名」，不是全局封禁。
- **代拍开关**（新功能）：场次编辑里勾选「本场支持代拍」，保存后自动生成一个独立代拍报名项，不占用任何常规时段。
- **多模特场次**（新功能）：场次可选多位模特（如双模特），下拉改为多选；第一位是主模特，海报主图与模特照片库取自主模特。前台模特栏按「A、B」形式展示。
- 模特档案新增「身高 / 三围单独同意」留痕。

### 修复
- **优惠券折扣计算错误**：8 折券此前被当成「减 80%」计算，导致实收只有原价的 20%。
  修复后按「减免 20%」计算，**同样的券会扣更多积分**（这是纠正少扣，不是涨价）。
- 场次编辑默认时段：自动生成「最近周日 15:00 起、每场 60 分钟 + 休息 10 分钟」三场。
- 海报标题排版：优先在 `·`、`／`、空格处断行，字号自动下探以容纳完整词组。

### 海报设计器（低代码排版，新功能）
- **入口**：后台「场次管理」→ 任一场次「导出海报」→「打开设计器」。
- **能做什么**：拖动区块移动、拖四角缩放、方向键微调（Shift 加速 10px）、Delete 删除；
  可改文案 / 字号 / 对齐 / 颜色，可替换图片源、切换「完整 / 裁切」填充；
  可复制区块、置顶置底、显示隐藏、自由「添加区块」（含自定义文字）。
- **保存后全局生效**：版式是**站点级**的，所有场次按同一版式导出；
  点「恢复预设」清空自定义版式，回到内置的经典 / 双人 / 通栏三选一。
- **预览即最终效果**：设计器画布调用与导出完全相同的渲染器，所见即所得。
- **二维码与标题不变**：码和标题仍在「海报配置」里改，设计器只存版式，互不覆盖。
- **拖动有对齐辅助线**：拖区块时自动吸附到其它区块的边缘 / 中线与画布中线，红色参考线标出对齐位置，松手消失。
- **点到的是看到的**：点击选中顺序与画面叠放顺序（z）一致。
  大图盖住小卡时，按住 `Alt`（Mac 为 `Option`）再点击，可在重叠的区块之间循环选中。
  本场不会绘制的区块（如单模特场次里的「第二模特图」）标记为「本场不显示」且**不再拦截点击**。

### 海报图区修复（本次报障）
- **修掉「导出的海报没有场地图和衣服图」**。
  根因：旧版只在「经典」版式里绘制右侧服装 / 场地小卡，
  而双模特场次默认选「双人」版式 —— 于是这两张图被静默丢弃。
  现在三套预设都含服装与场地区块，并给图片加了「当日服装 / 场地照片」角标。
- 海报标题断行去掉了残留分隔符（不再出现第二行以「· 」开头）。
- 「副标题 / 场地」与「场次安排」不再叠字：文字区块按自身矩形排布，宽度与高度都参与计算。

### 双模特：不再分主副，每人一套照片与服装
- **后台**：场次编辑的「图片」区改为**每位模特一张卡片**，各自选「本场照片」+ 上传「当日服装」，
  配置方式完全一致；「场地照片」仍是整场共用一份，不按模特重复上传。
- **海报**：新增「第二模特服装」区块，双人版式同时展示两张服装卡，
  角标带模特名（`当日服装 · 白電波`），不会再出现「两张服装分不清是谁」或「只有一份服装」。
  单模特场次自动跳过第二块；两位模特共用同一套服装时也不重复画（避免看起来像重复渲染的 bug）。
- **前台**：场次详情的图区改为按人分组（`模特照片 · A` / `服装照片 · A`），
  底部「模特」区从只显示一位改为**每人一张卡**，各自可查看资料、各自带本场服装缩略图。
- 数据是**增量**的：历史场次不填也能正常显示，自动回退到原来那组图。

### 修复：「修改时段必须同时提交分档价格」误拦截
- 现象：只想改个金额、或只想调个时间段，保存时被这条校验挡住，必须两边一起提交。
- 根因：`syncRelations` 里价格是整体替换（先 `DELETE` 再插入），
  所以早期用「两者必须同时提交」来防止「只传时段把价格删空」。
- 修复：把时段与价格的同步拆成两个独立开关（`syncSessions` / `syncPrices`），
  未提交的那一侧**完全不动**。现在只改价格不会碰时段，只改时段也不会碰价格。
- 报名详情接口补齐时段结束时间，修复票根显示 `15:00–08:00` 的问题。

> 否则前台只显示「可代拍」标签但没有可报名的入口。新场次会自动生成，无需额外操作。

## 四、上线步骤

```bash
# 1) 上传压缩包到服务器
scp photo-club-deploy.tar.gz root@<服务器>:/opt/

# 2) 解压（会覆盖 deploy/ 下的代码与前端产物，不动 data/ 与 .env.production）
cd /opt
tar -xzf photo-club-deploy.tar.gz

# 3) 进入部署目录执行
cd photo-club/deploy
chmod +x *.sh    # 若压缩包来自 Windows 打包，可执行位会丢失，必须先补
./deploy.sh
```

> **`Permission denied` 怎么办**：包内所有 `.sh` 已按 `0755` 打包，
> 用 `tar -xzf` 正常解压会保留权限。若你用的是旧包或用了会丢权限的解压工具
> （如某些图形化解压软件、Windows 自带解压向导），先执行 `chmod +x *.sh` 再跑；
> 也可以直接 `bash deploy.sh` —— `deploy.sh` 开头会自动对同目录所有脚本补 `+x`。
>
> `deploy.sh` 的行为：构建后端镜像 → 启动/复用 MySQL → 执行迁移 → 重建 server 与 nginx →
> 自检 nginx 配置 → 检查邀请码 → 部署后验证。
> **不会**停止或删除已有容器、数据卷与 `data/uploads`。

## 七、已知影响与注意事项

1. **优惠券折扣修复不追溯历史订单**。修复前用折扣券成交的记录仍是旧算法结果，不会自动更正。
2. **语义变化但数字不变**：原「189 元」现在显示为「189 积分」。数据库列名仍是 `fee_cent` 等，未做迁移，只是展示口径变了。
3. **会员等级仍是资格等级**（VIP/SVIP），与付费无关；积分不可购买、不可转让、不可兑现。
4. 本包**未包含** `.env.production`，服务器上已有的保持不变。
5. 本包**未包含** `data/uploads`，图片不受影响。
