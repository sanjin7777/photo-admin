位置 apps/server/src/modules/member-import.ts:494-525（:439-450 响应体）

原因 余额在流水之前无条件累加；流水靠 ON DUPLICATE KEY UPDATE idempotency_key = idempotency_key 静默忽略重复。同一份表重复提交时钱加两次而流水只有一条。该函数还直接 UPDATE balance_accounts，完全绕过 ledger.ts 的 FOR UPDATE + version + 唯一流水键三重保护。幂等键含 r.row（Excel 行号），换一份顺序不同的表即绕过。

const after = before + r.balanceCent;
await conn.execute('UPDATE balance_accounts SET available_cent = ?, version = version + 1 ...', [after, ...]);
if (r.balanceCent > 0) { await conn.execute(`INSERT INTO balance_transactions ... ON DUPLICATE KEY UPDATE idempotency_key = idempotency_key`, ...); }

建议 改为「先插流水（唯一键判重）成功 → 再改余额」，或直接复用 applyLedgerEntry；幂等键改为「文件指纹 + 用户 + 金额」，不得含行号；两段必须在同一事务内。

8.4 D3 · 邀请码注册（本次唯一全新功能）

规则：前台注册必须填邀请码；一个码只能用一次；由管理员在后台生成；管理员代注册（/admin/users）与 Excel 导入不消耗邀请码，否则老会员补录会被卡死；种子管理员账号由脚本直接创建，不需要码。

表结构（迁移 008，字段已为「用户端生成 + 奖励」预留）：

CREATE TABLE invite_codes (
  id             BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  code           CHAR(16)      NOT NULL COMMENT '去掉易混淆字符的随机码',
  status         ENUM('UNUSED','USED','REVOKED') NOT NULL DEFAULT 'UNUSED',
  created_by     BIGINT UNSIGNED NOT NULL COMMENT '生成人（管理员）',
  used_by        BIGINT UNSIGNED NULL,
  used_at        DATETIME(3)   NULL,
  expires_at     DATETIME(3)   NULL COMMENT 'NULL = 长期有效',
  note           VARCHAR(200)  NULL,
  source         ENUM('ADMIN','USER') NOT NULL DEFAULT 'ADMIN' COMMENT '预留：用户端生成',
  parent_user_id BIGINT UNSIGNED NULL COMMENT '预留：奖励归属',
  reward_cent    INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '预留：邀请奖励',
  created_at     DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at     DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  UNIQUE KEY uk_code (code),
  KEY idx_status (status, expires_at),
  KEY idx_creator (created_by)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

端点与能力：

端点说明
POST /auth/registerbody 增加必填 inviteCode（registerSchema 加字段，仍 .strict()）
POST /admin/invite-codes批量生成 { count, expiresAt?, note? }，服务端 crypto.randomBytes → Crockford Base32（剔除 0/O/1/I），一次性返回明文列表
GET /admin/invite-codes列表 + 状态/生成人筛选 + 分页（用真实 COUNT，别再用 rows.length 当 total）

注册事务（一码一次性的关键，必须条件 UPDATE + 行锁，不能只靠预检）：

await withTransaction(async (conn) => {
  const [rows] = await conn.execute(
    `SELECT id FROM invite_codes
      WHERE code = ? AND status = 'UNUSED'
        AND (expires_at IS NULL OR expires_at > NOW())
      FOR UPDATE`, [payload.inviteCode]);
  if (!rows[0]) throw new AppError(BIZ_CODES.INVITE_CODE_INVALID);
  // 微信号唯一预检 + INSERT users（复用现有 register 逻辑）
  const [used] = await conn.execute(
    `UPDATE invite_codes SET status='USED', used_by=?, used_at=NOW()
      WHERE id=? AND status='UNUSED'`, [userId, rows[0].id]);
  if (used.affectedRows !== 1) throw new AppError(BIZ_CODES.INVITE_CODE_USED); // 回滚整笔注册
});
